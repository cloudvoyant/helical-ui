`WhichKey` displays active multi-key chord prefixes and available next keys as you type. Click inside the workspace below and press `Space` for the leader menu, `g` for Goto, `z` for View, or `?` to search all bindings.

<Demo component="which-key" example="default" />

## Examples

### Leader Only

Set `leaderOnly` on `WhichKeyProvider` or `WhichKey` so the popup only appears for leader chords (`Space`) while non-leader chords (`gg`, `ge`, `gw`, `zt`) execute silently.

<Demo component="which-key" example="leader-only" />

### Modal Interaction

Pressing `Escape` when `WhichKey` is open inside an active `Dialog` closes only the `WhichKey` popup while keeping the underlying `Dialog` open.

<Demo component="which-key" example="modal-interaction" />

### Explorer

Press `?` or `Space ?` to open the searchable Keybinding Explorer modal, filter bindings by keyword, and press `Enter` to execute.

<Demo component="which-key" example="explorer" />

### Presets

Switch between Helix (`g e` to end, `Z` sticky View lock), Vim (`G` to end, `0` to start), and Kakoune (`V` sticky View lock) modal presets.

<Demo component="which-key" example="presets" />

### Panes

Move focus spatially across registered `Pane`s with `Space w h/j/k/l`, jump by index with `Space 1–3`, and traverse focus history with `Ctrl+o` and `Ctrl+i`.

<Demo component="which-key" example="panes" />

### Forms

Step across form controls with `j`/`k` in normal mode without typing into inputs, press `i` or `Enter` to enter insert mode, and press `Esc` to return to normal mode.

<Demo component="which-key" example="forms" />

### Jump Labels

Trigger 2D jump labels with `g w` to either focus or activate any visible interactive element.

<Demo component="which-key" example="jump-labels" />

## API Reference

### WhichKeyProvider

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `preset` | `'helix' \| 'vim' \| 'kakoune'` | `'helix'` | Active modal keybinding preset. |
| `defaultMode` | `'normal' \| 'select' \| 'insert' \| 'jump'` | `'normal'` | Initial modal state. |
| `leaderKey` | `string` | `'Space'` | Primary leader key (`<leader>?` opens `WhichKeyExplorer`). |
| `leaderOnly` | `boolean` | `false` | When `true`, only opens the `WhichKey` popup when the chord starts with `leaderKey` (e.g. `Space`), while non-leader chords (`gg`, `ge`, `gw`, `zt`) still execute silently. |
| `jumpAction` | `'focus' \| 'activate'` | `'activate'` | Whether forward jump labels (`gw` / `s`) focus or click the matched element. |
| `keymap` | `Record<string, WhichKeyNode>` | — | Additional prefix-trie keybindings merged into the active preset. |
| `commands` | `Record<string, KeymapHandler>` | — | Command handlers keyed by `commandId`. |
| `scoped` | `boolean` | `true` | Scopes keybinding handling to this provider's DOM subtree when multiple providers are mounted. |

### WhichKey

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'helix' \| 'modern' \| 'classic'` | `'helix'` | Floating panel layout style (`helix` bottom-right popup, `modern` centered card, `classic` bottom status bar). |
| `leaderOnly` | `boolean` | — | Optional per-panel override for `leaderOnly`; defaults to the active `WhichKeyProvider` setting. |
| `showExplorer` | `boolean` | `true` | Automatically mounts the `<leader>?` `WhichKeyExplorer` modal. |

### WhichKeyMode

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `mode` | `'normal' \| 'select' \| 'insert' \| 'jump'` | — | Optional mode override; defaults to the active `WhichKeyProvider` or document controller mode. |
| `sticky` | `boolean` | — | Optional sticky-lock override (`·lock` suffix); defaults to the active controller's sticky state. |
| `showPreset` | `boolean` | `false` | Prepends the active preset name (`helix · normal`). |
| `size` | `'sm' \| 'md' \| 'lg'` | `'sm'` | Badge size variant. |

### WhichKeyExplorer

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `open` | `boolean` | — | Optional controlled open state. |
| `onOpenChange` | `(open: boolean) => void` | — | Callback fired when the explorer Dialog opens or closes. |
| `placeholder` | `string` | `'Search keybindings...'` | Placeholder text for the filter input. |

### `useKeymap` & `RegisterKeymapOptions`

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `priority` | `'overlay' \| 'widget' \| 'extension' \| 'editor' \| 'pane' \| 'global'` | `'pane'` / `'global'` | Priority tier (`overlay` layers always run first, followed by deepest DOM `element`, priority tier, and registration recency). |
| `element` | `HTMLElement \| null \| (() => HTMLElement \| null)` | — | Optional DOM containment target checked against `event.target` / `document.activeElement` (deepest element wins). |
| `matchesTarget` | `(target: EventTarget \| null, event: KeyboardEvent) => boolean` | — | Optional custom predicate for filtering target elements. |
| `enabled` | `boolean \| (() => boolean)` | `true` | Static boolean or reactive getter controlling whether the keymap layer is active. |
| `scope` | `string` | — | Optional pane ID scope restriction. |
