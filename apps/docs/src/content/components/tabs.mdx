The Tabs component switches between related content panels. It is built on [Ark UI `tabs`](https://ark-ui.com/docs/components/tabs), sourced from [Shark UI](https://shark.vini.one/docs/components/tabs), sharing the `tabsListVariants`/`tabsIndicatorVariants` cva + part classes from `@cloudvoyant/helical-ui`. Use the framework selector in the top-right to switch between implementations.

## API Reference

### Tabs

#### Props

Accepts all [Ark `TabsRoot` props](https://ark-ui.com/docs/components/tabs) plus `className`/`class`. Defaults `lazyMount` and `unmountOnExit` to `true`.

### TabsList

#### Props

| Prop      | Type                       | Default     | Description                                  |
| --------- | -------------------------- | ----------- | -------------------------------------------- |
| `variant` | `'default' \| 'underline'` | `'default'` | Pill (default) or underline indicator style. |

Also accepts all [Ark `TabList` props](https://ark-ui.com/docs/components/tabs). Renders the Ark `TabIndicator` inside the list.

### TabsTrigger

#### Props

Accepts all [Ark `TabTrigger` props](https://ark-ui.com/docs/components/tabs). `value` is required and must match a `TabsContent` panel; `disabled` prevents selection.

### TabsContent

#### Props

Accepts all [Ark `TabContent` props](https://ark-ui.com/docs/components/tabs). `value` is required and must match a `TabsTrigger`.

### useTabs

Returns Ark's [tabs context](https://ark-ui.com/docs/components/tabs#context) — `value`, `focusedValue`, `setValue`, `selectNext`, `selectPrev`, and friends — for programmatic control.

## Accessibility

Follows the [Tabs WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/). Ark sets `role="tablist"`/`role="tab"`/`role="tabpanel"`, `aria-selected`, and `aria-controls`; arrow keys rove between triggers and `Tab` moves focus to the active panel.

## Keybindings

When wrapped in a [`WhichKeyProvider`](/helical-ui/components/which-key), `Tabs` natively supports modal tab navigation across the Helix, Vim, and Kakoune presets:

| Keybinding | Action |
| --- | --- |
| `g n` / `g t` / `] t` | Activate the next tab in the active tablist (supports numeric counts such as `2 g t`). |
| `g p` / `g T` / `[ t` | Activate the previous tab in the active tablist. |
| `l` / `w` / `e` | Activate the next tab when focused on a horizontal tab trigger. |
| `h` / `b` | Activate the previous tab when focused on a horizontal tab trigger. |
| `j` / `k` | Activate the next or previous tab when focused on a `vertical` tablist trigger. |
| `0` / `g h` | Activate the first tab in the active tablist. |
| `$` / `g l` | Activate the last tab in the active tablist. |
| `g w` (`s` in Vim) | Overlay 2D jump labels on all visible tabs (including inactive tabs) and click/focus the selected tab. |

## Theming

No theme extension is required — the indicator and hover states use existing tokens (`bg-accent`, `bg-primary`, `text-muted-foreground`, `--radius-*`), light and dark.
