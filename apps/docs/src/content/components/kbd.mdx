## API Reference

### Kbd

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'outline' \| 'subtle' \| 'solid'` | `'outline'` | Visual style of the keycap. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Keycap size. |
| `hotkey` | `KbdHotkey` | — | Hotkey chord or multi-step sequence (`'Mod+K'`, `'Space w v'`, `['Space', '?']`) validated and formatted via `@tanstack/hotkeys` with automatic platform inference. Malformed chords log a console warning and render with `data-invalid="true"` destructive styling. |
| `useSymbols` | `boolean` | `true` | Whether to render symbol glyphs or text labels for modifiers. |
| `className` / `class` | `string` | — | Additional Tailwind classes merged via `cn`. |
