## API Reference

### Kbd

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'outline' \| 'subtle' \| 'solid'` | `'outline'` | Visual style of the keycap. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Keycap size. |
| `hotkey` | `string \| string[]` | — | Optional chord or sequence string/array formatted automatically into platform symbols. |
| `platform` | `'mac' \| 'windows' \| 'linux'` | `'mac'` | Target platform for modifier symbol formatting (`⌘`, `⌃`, `⌥`, `⇧`). |
| `useSymbols` | `boolean` | `true` | Whether to render symbol glyphs or text labels for modifiers. |
| `className` / `class` | `string` | — | Additional Tailwind classes merged via `cn`. |
