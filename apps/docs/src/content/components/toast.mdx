`Toast` displays brief, non-blocking notification overlays. Mount `<Toaster />` once in your root layout, and trigger notifications anywhere using the `useToast()` hook or the `toast` service (`toast.create({ title, description, type, action })`).

## API Reference

### Toaster

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `toaster` | `CreateToasterReturn` | `toast` | Toast store created by `createToaster({ placement, overlap, max })`. |
| `children` | `(toast: ToastOptions) => ReactNode` / `Snippet<[() => ToastOptions]>` | `<ToastItem />` | Optional custom renderer for each toast item. |

Accepts all [Ark `ToasterProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### Store & Hooks

- `useToast(toaster?)` — Returns the active toast service (`toast` by default) for triggering notifications (`toast.create`, `toast.success`, `toast.error`, `toast.info`, `toast.warning`, `toast.dismiss`).
- `toast` — Shared singleton toast service (`placement: 'bottom-end'`, `overlap: true`, `max: 5`) wired to `<Toaster />`.
- `createToaster(props)` — Creates a custom isolated toast store (`placement`, `overlap`, `max`, `gap`, `offsets`).
- `useToastContext()` — Reads the current individual `<ToastRoot>` item state from context.
