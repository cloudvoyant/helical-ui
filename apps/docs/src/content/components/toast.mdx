`Toast` displays brief, non-blocking notification overlays. Create a store with `createToaster` (or use the default `toast` singleton), mount `<Toaster />` once, and trigger notifications imperatively with `toaster.create({ title, description, type, action })`.

## API Reference

### Toaster

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `toaster` | `CreateToasterReturn` | `toast` | Toast store created by `createToaster({ placement, overlap, max })`. |
| `children` | `(toast: ToastOptions) => ReactNode` / `Snippet<[() => ToastOptions]>` | `<ToastItem />` | Optional custom renderer for each toast item. |

Accepts all [Ark `ToasterProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastItem

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `toast` | `ToastOptions` | — | Toast item data (`title`, `description`, `type`, `action`, `closable`). |

Accepts all [Ark `ToastRootProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastRoot

Accepts all [Ark `ToastRootProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastTitle

Accepts all [Ark `ToastTitleProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastDescription

Accepts all [Ark `ToastDescriptionProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastActionTrigger

Accepts all [Ark `ToastActionTriggerProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`.

### ToastCloseTrigger / ToastDismiss

Accepts all [Ark `ToastCloseTriggerProps`](https://ark-ui.com/docs/components/toast) plus `className`/`class`. Ships with `aria-label="Close"`.

### Store & Hooks

- `createToaster(props)` — Creates a toast store (`placement`, `overlap`, `max`, `gap`, `offsets`).
- `toast` — Default preconfigured toaster store (`placement: 'bottom-end'`, `overlap: true`, `max: 5`).
- `useToast` / `useToastContext` — Reads the current toast item state from context.
